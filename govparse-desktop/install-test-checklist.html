GovParse Desktop 설치 확인표

다른 Windows PC에 설치해서 제대로 동작하는지 확인하는 순서입니다. 위에서부터 차례로 해 보고, 각 줄의 결과 칸에 ✓ 또는 ✗를 표시하세요. 20~30분 걸립니다.

테스트한 PC

날짜 · 확인한 사람
Windows 버전Windows 10 / 11 (시작 › 설정 › 시스템 › 정보)
한글(한컴오피스)설치됨 (버전:        ) / 설치 안 됨
govparse 엔진·LM Studio있음 / 없음  (없는 PC에서 시험하는 것이 목적입니다)
인터넷연결 / 끊음  (끊고 해 보면 더 확실합니다)

준비물

  • 설치 파일 GovParse-Desktop-Setup-x64.exe (약 149MB)
  • 시험할 문서 HWPX 1개, HWP 1개. 그림과 표가 들어 있는 문서가 좋습니다. 업무 문서를 쓴다면 외부로 나가지 않는 PC에서 시험하세요.
설치 파일이 전달 중에 손상되지 않았는지 확인하려면 PowerShell에서 Get-FileHash .\GovParse-Desktop-Setup-x64.exe를 실행해 아래 값과 같은지 봅니다.
SHA-256: 810672b262bc71dd632e20585051f6fb856cee7b16b1b3720076685ab1991cf9

1. 설치

#할 일이렇게 되면 정상결과
1설치 파일을 더블클릭합니다.“GovParse Desktop 0.3.0을 설치합니다” 창이 뜹니다. 관리자 권한(방패 아이콘) 창은 뜨지 않습니다.✓ ✗
“Windows의 PC 보호” 파란 창이 뜨면 서명되지 않은 프로그램이라서입니다. 추가 정보 › 실행을 누르세요. 회사 보안 프로그램이 막으면 그 내용을 아래 메모 칸에 적어 주세요.
2확인을 누릅니다.1분 안에 “설치가 완료되었습니다” 창이 뜹니다.✓ ✗
3바탕 화면과 시작 메뉴를 봅니다.둘 다 GovParse Desktop 아이콘이 있습니다.✓ ✗
4“지금 실행할까요?”에서 예를 누릅니다.앱 창이 뜨고 “HWP 또는 HWPX 파일을 여기에 놓으세요”가 보입니다.✓ ✗

2. 문서 열기

#할 일이렇게 되면 정상결과
5파일 열기로 HWPX 문서를 엽니다.위쪽 초록 글씨에 “구조 읽기 완료 · 문단 … · 표 … · 그림 …”이 나오고, 가운데에 문서 쪽이 보입니다.✓ ✗
6다음 버튼으로 몇 쪽 넘겨 봅니다.쪽 번호가 바뀌고 내용이 바뀝니다.✓ ✗
7HWP 문서도 엽니다.한글이 있는 PC: 5번과 같이 보입니다.
한글이 없는 PC: 대부분 열리지만, 일부 문서는 “한글이 필요합니다” 같은 안내가 나올 수 있습니다. 나온 문구를 적어 주세요.		✓ ✗

3. 그림 글자 읽기 (OCR)

#할 일이렇게 되면 정상결과
8설정을 누릅니다.“RapidOCR · PP-OCRv5 한국어”가 진하게(선택 가능하게) 보입니다. 흐리게 “사용할 수 없음”이 나오면 실패입니다.✓ ✗
9설정을 닫고 그림 목록에서 글자가 있는 그림(로고 등)을 고른 뒤 이 그림 OCR을 누릅니다.30초 안에 아래 칸에 그림 속 글자가 나옵니다. 위에 “RapidOCR”이라고 표시됩니다.✓ ✗
10그림을 고른 상태에서 Ctrl+C를 누르고, 메모장이나 그림판에 붙여 넣습니다.그림판에 그림이 붙습니다.✓ ✗

4. 내보내기

#할 일이렇게 되면 정상결과
11아래 내보낼 형식을 JSON + PNG로 두고 내보내기를 누른 뒤 저장 위치를 고릅니다.아래 줄에 진행 상황이 나오고, 끝나면 “저장 완료 · … · 압축 파일 ….zip”이 나옵니다.✓ ✗
12위쪽 결과 보기를 누릅니다.오른쪽에 그림·표 목록이 나오고, 하나를 고르면 왼쪽에 그 그림이 보입니다.✓ ✗
13압축 파일 보기를 누릅니다.파일 탐색기가 앞으로 나오고 .zip 파일이 선택돼 있습니다. 압축을 풀면 document.json과 assets 폴더가 있습니다.✓ ✗
14같은 화면에서 HWPX로 변환을 누릅니다.변환된 문서가 결과 보기에 쪽 단위로 나옵니다.✓ ✗
15원본 보기로 돌아가 형식을 HTML로 바꿔 내보내고, 브라우저에서 열기를 누릅니다.브라우저에 문서가 열리고 그림이 보입니다.✓ ✗
16한글이 있는 PC만: 형식을 HWP로 바꿔 내보내고 한글에서 열기를 누릅니다.한글이 열리고 문서가 보입니다. 앱이 연 한글 창 말고 원래 열려 있던 한글 창은 닫히지 않습니다.✓ ✗
16-111번의 JSON + PNG 결과에서 결과 보기 › 표 고치기를 누릅니다.표 목록이 나오고, 표를 고르면 왼쪽에 표 그림, 오른쪽에 칸이 나옵니다. 상태는 “원본 표에서 읽음”입니다.✓ ✗
16-2칸 하나를 더블클릭해 글자를 고치고 저장을 누릅니다.상태가 “사람이 고침 · 1칸”으로 바뀌고, 아래 상태 줄에 “표를 저장했습니다”가 나옵니다.✓ ✗
16-3표 고치기 닫기를 누른 뒤, 결과 불러오기로 같은 document.json을 다시 열고 표 고치기를 누릅니다.고친 글자가 그대로 있고 상태가 “사람이 고침 · 1칸”입니다.✓ ✗
16-4“검사 전” 또는 “표 구조 확인 못함”인 표가 있을 때만: 그 표를 고르고 이미지에서 표 읽기를 누릅니다.몇 초 뒤 칸이 채워지고 상태가 “이미지에서 읽음 · 확인 필요”가 됩니다. 칸을 고르면 왼쪽 그림에 테두리가 나옵니다.✓ ✗

5. 다시 열기 · 제거

#할 일이렇게 되면 정상결과
17앱을 닫고 바탕 화면 아이콘으로 다시 엽니다. 결과 불러오기로 11번의 document.json을 엽니다.결과 보기에 “원본파일명 → document.json” 제목과 그림 목록이 나옵니다.✓ ✗
18설치 파일을 한 번 더 실행합니다.“기존 GovParse Desktop을 새 버전으로 바꿉니다” 창이 뜨고 설치가 끝납니다. 앱이 켜져 있으면 “닫은 뒤 다시 시도” 안내가 나옵니다.✓ ✗
19시작 › 설정 › 앱 › 설치된 앱에서 GovParse Desktop을 찾아 제거합니다.“제거했습니다”가 나오고, 바탕 화면·시작 메뉴 아이콘이 사라집니다. 11번에서 저장한 결과 폴더와 zip은 남아 있습니다.✓ ✗
19-1다시 설치한 뒤: 앱의 설정 › 프로그램 제거…를 누르고 확인합니다.앱이 닫히고 “제거했습니다”가 나옵니다. 설치 폴더에 uninstall.exe도 남지 않습니다.✓ ✗

문제가 생겼을 때 적어 주세요

번호화면에 나온 문구 (그대로) · 스크린샷 파일명
함께 보내 주면 원인 찾기가 빠릅니다: 실패한 화면의 스크린샷(Win+Shift+S), 아래 줄의 상태 문구.
알려진 제약: HWP로 내보내기, HWP 원본의 그림 위치, ‘한글에서 열기’는 한글(한컴오피스)이 설치된 PC에서만 됩니다. 1,000쪽이 넘는 문서는 JSON + PNG 내보내기에 수십 분 걸릴 수 있습니다.
