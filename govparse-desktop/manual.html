GovParse Desktop 사용 설명서

Windows x64용 0.1.0 로컬 배포판. 문서를 인터넷으로 보내지 않고 HWP·HWPX를 열어 JSON, PNG, HTML 또는 편집 가능한 HWPX를 저장합니다.

1. 다른 PC에 설치하기

  1. Windows 10 또는 11 x64 PC에 GovParse-Desktop-Windows-x64.zip를 복사합니다. .NET Framework 4.5 이상과 현재 사용자의 앱 설치 권한이 필요합니다.
  2. ZIP 전체를 로컬 폴더에 압축 해제하고 install.cmd를 더블클릭합니다. app.zip은 install.cmd와 같은 위치에 두세요. 개인 배포용으로 코드 서명이 없습니다. 조직에서 서명된 앱만 허용하면 관리자에게 배포를 문의하세요.
  3. 시작 메뉴에서 GovParse Desktop을 엽니다. Python, Java, LM Studio, API 키, 한컴오피스 및 인터넷 연결은 기본 기능에 필요하지 않습니다.

2. 원본 보기

파일 하나를 창에 끌어놓거나 파일 열기(Ctrl+O)를 누르세요. 첫 쪽이 나타나면 이전 쪽·다음 쪽으로 이동합니다. 내장 rhwp 렌더러가 그리므로 설치된 한글 글꼴이나 문서 구성에 따라 한컴에서 보이는 쪽 배치와 다를 수 있습니다.

3. 내보내기

아래 목록에서 형식을 고르고 내보내기를 누른 다음 결과를 저장할 상위 폴더를 선택하세요. 작업이 끝나면 새 결과 폴더가 열립니다. 입력 파일은 그대로 유지됩니다.

선택확인할 파일
JSON + PNGdocument.json의 body에 문단과 표가 있습니다. assets에 추출 가능한 그림과 감지한 표의 캡처가 저장됩니다. desktop_export.table_captures에는 페이지 번호와 상대 경로가 들어갑니다. OCR은 이 배포판에 포함하지 않습니다.
HTMLdocument.html을 브라우저로 엽니다. 다른 곳으로 옮길 때 assets 폴더도 함께 복사하세요.
한글 문서 (.hwpx)document.hwpx를 한글 또는 호환 뷰어에서 엽니다. 본문과 표가 편집 가능한 형태로 복원됩니다. 그림·서식·원본 페이지 배치는 보존되지 않을 수 있습니다. 바이너리 .hwp 저장은 지원하지 않습니다.

4. 문제가 생기면

먼저 작은 HWPX로 시험해 보세요. 미리보기 실패 시 내보내기를 별도로 시도할 수 있습니다. PNG가 없으면 문서에 그림이 없는지, 선이 없는 표 등으로 인해 표 검출에서 누락됐는지 원본과 대조하세요. 그림 처리 경고는 결과 폴더의 warnings.txt에서 확인합니다. 대형 파일은 작업당 최대 10분까지 기다립니다. 쓰기 오류가 나면 사용자 문서 폴더처럼 저장 가능한 위치를 다시 선택하세요.

5. 제거 및 데이터

앱을 닫고 시작 메뉴의 GovParse Desktop 바로가기와 %LOCALAPPDATA%\GovParse Desktop\0.1.0 폴더를 삭제합니다. 이 버전은 사용자별 폴더 설치 방식입니다. 사용자가 선택한 위치에 저장한 결과물은 별도로 관리합니다. 앱 폴더의 licenses에 포함 구성요소의 라이선스가 있습니다.
