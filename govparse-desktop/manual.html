GovParse Desktop 사용 설명서

Windows x64용 0.3.0 로컬 배포판. 문서를 인터넷으로 보내지 않고 HWP·HWPX를 열어 JSON, PNG, HTML 또는 편집 가능한 HWPX를 저장합니다.

1. 다른 PC에 설치하기

  1. Windows 10 또는 11 x64 PC에 GovParse-Desktop-Setup-x64.exe를 복사합니다. 관리자 권한은 필요 없습니다.
  2. 설치 파일을 더블클릭하고 안내에 따라 설치합니다. 서명되지 않은 파일이라 ‘Windows의 PC 보호’ 창이 뜨면 ‘추가 정보’ › ‘실행’을 누릅니다.
  3. 바탕 화면이나 시작 메뉴의 GovParse Desktop으로 엽니다. Python, Java, LM Studio, API 키, 한컴오피스, 인터넷 연결은 기본 기능에 필요하지 않습니다.

2. 문서 열기와 원본 보기

HWP 또는 HWPX 파일 하나를 창에 끌어다 놓거나 파일 열기(Ctrl+O)를 누릅니다. 첫 쪽이 나타나면 이전·다음으로 쪽을 넘기고, 폭 맞춤 ▾에서 크기를 바꿉니다. 원본 파일은 읽기만 하고 바꾸지 않습니다.

창 위쪽의 상태 줄에 문서에서 읽은 문단·표·그림 수와 진행 상황이 나옵니다. 원본 보기는 앱에 들어 있는 미리보기 프로그램(rhwp)이 그리므로, 글꼴이나 문서 구성에 따라 한글에서 보는 쪽 배치와 다를 수 있습니다.

미리보기 주의 안내

미리보기 프로그램이 그림과 표를 겹쳐 그릴 수 있는 문서를 열면, 원본 보기 위에 주황색 미리보기 주의 안내가 뜨고 어느 표인지 알려 줍니다. 화면 표시만의 문제이고 문서와 내보낸 결과는 정상입니다. 정확한 모양은 원본 문서(한글)에서 확인하세요. 한글(한컴오피스)이 설치된 PC에서는 설정 › 미리보기 방식 › 한컴오피스로 그리기를 고르면 원본과 같은 모양으로 보입니다. 이 방식은 문서를 처음 열 때 전체를 PDF로 바꾸므로 큰 문서는 몇 분 걸리고, 그림 목록의 위치 표시가 나오지 않습니다.

3. 그림 목록과 그림 설명

원본 보기에서 그림 목록을 누르면 문서 안의 그림이 오른쪽에 나옵니다. 그림을 고르면 원본 쪽에서 그 그림의 위치가 표시되고, 앱이 찾은 설명(캡션) 후보가 보입니다. 그림 설명 편집을 누르면 후보 문장을 고르거나, 그림을 OCR로 읽은 글을 넣거나, 직접 적어 설명 저장(Ctrl+S)으로 저장할 수 있습니다. 여기서 정한 설명은 원본 문서가 아니라 이 PC의 기록에 저장되며, 내보낼 때 결과에 함께 들어갑니다.

4. 내보내기

아래쪽 내보낼 형식에서 형식을 고르고 내보내기를 누른 뒤 저장할 폴더를 고릅니다. 끝나면 결과 보기로 넘어갑니다. 진행 중에는 Esc 또는 취소로 멈출 수 있습니다. 같은 이름의 결과가 있으면 덮어쓰지 않고 새 이름으로 저장합니다.

형식만들어지는 것
JSON + PNGdocument.json(문단·표·그림 구조), assets 폴더의 그림과 표 그림, tables 폴더의 표 정보(표 고치기에 사용). 같은 이름의 .zip도 결과 폴더 옆에 만듭니다.
HTMLdocument.html. 브라우저로 엽니다. 다른 곳으로 옮길 때는 assets 폴더도 함께 옮기세요.
한글 문서 · HWPXdocument.hwpx. 본문·표·그림을 편집 가능한 형태로 복원합니다. 원본의 글꼴·문단 서식·쪽 배치는 그대로 복원하지 않습니다.
한글 문서 · HWPdocument.hwp. 한글(한컴오피스)이 설치된 PC에서만 고를 수 있습니다.

큰 문서는 JSON + PNG 내보내기가 오래 걸립니다. 표마다 그림을 따로 만들기 때문에, 표가 2천 개가 넘는 문서는 한 시간 이상 걸릴 수 있습니다. 상태 줄에 단계와 진행 수가 나옵니다.

5. 결과 보기

내보낸 직후나 결과 불러오기로 document.json·document.html·document.hwpx를 열면 결과가 나옵니다. 제목에는 원본 파일 이름이 함께 보입니다.

  • 자산 목록: 내장 그림, 표 이미지(또는 원본 쪽), 이미지를 만들지 못한 표와 그 사유. 줄을 고르면 왼쪽에 그림이 보이고, Ctrl+C나 오른쪽 클릭으로 그림을 복사할 수 있습니다.
  • 이 그림 OCR: 고른 그림 속 글자를 읽습니다. 앱 안에 들어 있는 모델로 인터넷 없이 동작합니다. 어떤 방식으로 읽을지는 설정 › OCR 엔진에서 고릅니다.
  • HTML로 변환·HWPX로 변환: 원본 파일 없이 JSON 결과에서 바로 만듭니다.
  • JSON 열기·폴더 열기·압축 파일 보기: 결과 파일의 위치를 엽니다. 다른 사람에게 보낼 때는 .zip 하나를 보내면 됩니다. 앱은 결과 폴더를 읽으므로 폴더는 지우지 마세요.
  • 결과 파일이 저장 뒤에 바뀌었는지도 표시합니다(“저장 후 변경 없음”).

6. 표 고치기

JSON + PNG로 내보낸 결과에서, 문서의 표를 칸 단위로 확인하고 고칠 수 있습니다.

  1. 결과 보기에서 표 고치기를 누릅니다. 위쪽에 표 목록, 아래쪽에 고른 표의 칸이 나오고, 왼쪽에는 그 표의 그림이 보입니다.
  2. 칸을 더블클릭하거나 F2를 눌러 글자를 고칩니다. 칸 안에서 줄을 바꾸려면 Shift+Enter를 누릅니다.
  3. 칸에서 오른쪽 클릭하면 행·열을 추가하거나 지울 수 있습니다. 병합된 칸이 있는 표는 글자만 고칠 수 있습니다. 칸 안에 표가 들어 있으면 ‘안쪽 표 열기’로 그 표로 이동합니다.
  4. 저장을 누릅니다. 목록의 상태가 ‘사람이 고침 · N칸’으로 바뀝니다. ‘되돌리기’는 마지막 한 동작을, ‘처음 읽은 표로’는 전체를 되돌립니다.
  5. 끝나면 표 고치기 닫기를 누릅니다.

앱이 문서에서 읽은 표(tables/table-….json)는 바꾸지 않고, 고친 내용만 같은 폴더의 ….edited.json에 따로 저장합니다. 결과 폴더를 다른 곳으로 옮겨도 고친 내용이 따라갑니다. 내보낼 때 만든 압축 파일(.zip)에는 그 뒤에 고친 내용이 들어 있지 않으므로, 고친 뒤에 보낼 때는 결과 폴더를 다시 압축하세요. 이전 버전으로 내보낸 결과에는 표 정보가 없어 ‘검사 전’으로만 나옵니다. 그 문서를 다시 내보내면 고칠 수 있습니다.

목록의 상태뜻
원본 표에서 읽음문서의 칸을 그대로 읽은 표
사람이 고침 · N칸고쳐서 저장한 표
저장 안 됨 · N칸고쳤지만 아직 저장하지 않은 표
이미지에서 읽음 · 확인 필요표 그림에서 추정해 읽은 표. 사람이 확인해야 합니다
사람이 확인함그림에서 읽은 표를 확인하고 저장함
검사 전 / 표 구조 확인 못함 / 검사 실패칸 정보가 없는 표. 표 그림은 그대로 볼 수 있습니다

그림으로만 남은 표 읽기

문서에서 칸을 읽지 못한 표(상태가 ‘검사 전’ 또는 ‘표 구조 확인 못함’)는 표 그림에서 읽을 수 있습니다. 표를 고르고 이미지에서 표 읽기를 누릅니다. ‘글자도 읽기 (OCR)’를 켜 두면 칸의 글자도 함께 읽습니다. 읽은 결과는 추정이라 행·열 수나 병합, 글자가 틀릴 수 있습니다. 아직 확인하지 않은 칸은 주황색으로 표시되고, 칸을 고르면 왼쪽 그림에 그 칸의 위치가 테두리로 나옵니다. 그림과 대조해 고친 뒤 확인 후 저장을 누르면 ‘사람이 확인함’ 또는 ‘사람이 고침’으로 기록됩니다. 문서에서 칸을 읽은 표에는 이 단추가 나오지 않습니다(문서에서 읽은 칸이 더 정확합니다). 그림이 원본 쪽 전체이거나 여러 쪽에 걸친 표는 읽을 수 없습니다.

7. 설정

  • OCR 엔진: ‘이 그림 OCR’이 글자를 읽는 방법. 쓸 수 없는 엔진은 이유와 함께 흐리게 표시됩니다.
  • 미리보기 방식: 기본 미리보기(rhwp) 또는 한컴오피스로 그리기(한글이 설치된 PC만).
  • 프로그램 제거…: 확인 뒤 프로그램이 닫히고 제거됩니다.

설정은 %LOCALAPPDATA%\GovParse Desktop\settings.json에 저장됩니다.

8. 설치·업데이트·제거

설치 파일은 관리자 권한 없이 %LOCALAPPDATA%\GovParse Desktop\app에 설치하고 바탕 화면과 시작 메뉴에 바로 가기를 만듭니다. 새 설치 파일을 다시 실행하면 기존 버전을 바꿉니다(실패하면 이전 버전으로 되돌립니다). 제거는 설정 › 프로그램 제거… 또는 Windows 설정 › 앱 › 설치된 앱에서 합니다. 설치·업데이트·제거 모두 저장한 결과물, 설정, 그림 설명 기록은 지우지 않습니다.

OCR 모델과 표 구조 모델은 앱 안에 들어 있어 인터넷 없이 동작합니다. HWP로 내보내기, ‘한글에서 열기’, 한컴 미리보기는 한글(한컴오피스)이 설치된 PC에서만 됩니다. 앱 폴더의 licenses에 포함된 구성 요소와 모델의 라이선스·출처가 있습니다.

필요 사양: Windows 10 또는 11 (64비트). 그래픽 카드는 쓰지 않습니다. 메모리는 8GB 이상을 권합니다(1,000쪽이 넘는 문서를 열 때 수백 MB, 큰 문서를 내보낼 때는 수 GB를 씁니다).

9. 문제가 생기면

  • 미리보기가 실패하거나 이상하게 보임: 내보내기는 미리보기와 따로 동작하므로 그대로 할 수 있습니다. 겹쳐 보이는 경우는 2절의 ‘미리보기 주의 안내’를 보세요.
  • 표 고치기에서 표가 ‘검사 전’으로만 나옴: 이전 버전으로 내보낸 결과입니다. 이 버전으로 다시 내보내세요.
  • ‘이미지에서 표 읽기’ 결과가 틀림: 추정이라 틀릴 수 있습니다. 칸을 고쳐 저장하거나, 오른쪽 클릭으로 행·열을 맞춘 뒤 저장하세요.
  • 표 이미지가 없는 표: 자산 목록 끝에 사유와 함께 나옵니다.
  • 저장할 수 없음: 원본과 같은 폴더·이름에는 저장하지 않습니다. 문서 폴더처럼 쓸 수 있는 위치를 고르세요.
  • 내보내기가 오래 걸림: 큰 문서의 JSON + PNG는 오래 걸립니다(4절). 급하면 HTML이나 HWPX로 먼저 내보내세요.

10. (선택) LM Studio에서 AI에게 표 이미지 요청하기

이 절은 govparse MCP 서버를 따로 설치해 쓰는 경우에만 해당합니다. Desktop 앱만 쓸 때는 필요 없습니다.

Desktop에서 직접 내보낼 때는 JSON + PNG를 고르세요. 대화로 같은 문서의 특정 표를 요청하려면 LM Studio에 govparse MCP 서버를 등록하고 연결하세요. 도구 목록에 extract_hwp_table_images가 보이는 버전이 필요합니다.

  1. 채팅에 “govparse로 C:/문서/사업안내 폴더를 등록하고 HWP 파일 목록을 보여 줘.”라고 입력하세요. AI가 prepare_corpus와 list_documents를 호출합니다. 폴더 경로는 내 PC의 실제 경로로 바꾸세요.
  2. 목록에서 문서를 골라 “이 문서의 표 목록을 이미지 생성 없이 보여 줘. 각 표의 ID와 첫 셀 내용도 알려 줘.”라고 요청하세요. AI는 list_only=true로 조회한 뒤 응답의 table_images_ir_json 파일을 읽어 표를 찾을 수 있습니다. 이 파일을 읽으려면 클라이언트에서 결과 폴더에 접근할 수 있어야 합니다.
  3. “두 번째 표만 PNG로 만들어서 파일 경로를 알려 줘.”라고 요청하세요. 여러 쪽으로 나뉘면 table_image.paths에 순서대로 들어 있습니다. 상대 경로는 응답의 image_dir를 기준으로 엽니다. 전체 표를 원하면 “모든 표를 PNG로 만들어 줘”라고 요청하세요.

자동 생성되는 스키마는 어디에 쓰나요?

AI가 도구에 어떤 값을 보내야 하는지 알려 주는 명세를 입력 스키마라고 합니다. 엔진은 도구 함수의 인수와 타입에서 이 명세를 자동으로 만들고, MCP 클라이언트가 tools/list를 요청하면 각 도구의 inputSchema로 제공합니다. 일반 사용자는 채팅에 원하는 작업만 적으면 됩니다. 문서의 셀과 본문 내용은 파싱 결과 JSON에서 확인합니다.

표 이미지 도구의 스키마와 호출 예시 보기

자동 생성된 입력 스키마에서 표시용 제목을 생략한 예입니다. doc_name만 필수입니다.

{
  "type": "object",
  "required": ["doc_name"],
  "properties": {
    "doc_name": {"type": "string"},
    "table_ids": {"anyOf": [{"type": "array", "items": {"type": "string"}}, {"type": "null"}], "default": null},
    "list_only": {"type": "boolean", "default": false}
  }
}

다음은 표 하나를 받는 MCP 요청 예시입니다. 파일명과 표 ID는 앞에서 조회한 값으로 바꾸세요.

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "extract_hwp_table_images",
    "arguments": {"doc_name": "사업안내.hwp", "table_ids": ["s0/b2/t0"]}
  }
}

결과가 partial이면 manifest_path의 파일에서 각 표의 생성 여부와 사유를 확인하세요.
