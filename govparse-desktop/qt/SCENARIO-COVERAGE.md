# 사용자 시나리오 대비 화면 사양 테스트 충족 여부

기준은 두 가지입니다. 사용자가 정리한 사용 시나리오(2026-11-25)와 `design.md`의 적대적 인수 시나리오입니다.
판정은 이렇게 표시합니다.
- **충족**: 기능이 있고 테스트가 그 흐름을 검사함
- **부분**: 일부만 있거나 일부만 검사함
- **없음**: 기능 자체가 없음

## 1. 사용자 사용 시나리오

| 시나리오 | 지금 기능 | 테스트 | 판정 |
|---|---|---|---|
| **AI에게 정보 공유용 파싱** (JSON + PNG) | 내보내기, 표별 PNG와 표 ID, 결과 폴더 기준 상대 경로, zip 하나로 전달 | `test_json_export_publishes_zips_and_reports`, `test_moved_result_reopens`, `test_json_export_then_result_view` | 충족 |
| **표·이미지 중에서 검색해 관련 이미지 찾기** | **검색 기능 없음.** 그림 목록 필터는 설명 유무로만 거름. 결과 목록에도 검색 칸 없음 | 없음 | **없음** |
| **파싱된 이미지를 보다가 원문 위치 찾기** | 원본 쪽 그림 목록에서 고르면 그 쪽으로 이동해 상자 표시. **결과 보기의 이미지(자산 목록)에서 원문으로 가는 동작은 없음.** 표 이미지는 엔진이 원문 쪽을 주지 않음(`page_hint` 비어 있음) | `test_verified_figure_jumps_to_its_page_and_boxes_it`, MCP `test_show_reselects_and_jumps` | **부분** |
| **품질 확인을 위한 원본 대조** (HTML, 복원 HWPX) | 결과 탭에서 HTML·HWPX를 보고 원본 탭과 번갈아 봄. **나란히 보기·같은 위치 맞추기는 없음.** | `test_html_result`, `test_hwpx_result_pages` | **부분** |
| 핵심 버튼 3단계 (원본 보기 ~ 내보내기) | 모두 있음 | 1·2절 테스트 | 충족 |
| 그림 목록 필터, 이 그림 OCR, 텍스트 복사 | 있음 | `test_filter`, `test_ocr_run_and_copy` | 충족 |
| 그림 선택 시 그 쪽으로 이동 | 있음 | `test_verified_figure_jumps_to_its_page_and_boxes_it` | 충족 |
| 로고 OCR `소 o` 문제 | 엔진 공통 OCR(1024px 축소 + 여백)로 `중소벤처기업부` | 워커 실측 테스트에만 있음. 화면 통합 테스트에는 OCR 품질 검사가 없음 | **부분** |
| `그림 설명 편집`으로 이름 변경, 설명 직접 입력 | 있음 | `test_edit_mode_groups`, `test_save_typed_caption_with_ctrl_s` | 충족 |
| OCR 결과를 설명으로 넣기 | `설명 칸에 넣기` 후 저장 | `test_ocr_text_into_caption` | 충족 |

## 2. design.md 적대적 인수 시나리오

| 상황 | 테스트 | 판정 |
|---|---|---|
| 다른 폴더의 **같은 이름** 파일 A, B를 차례로 열고 A가 늦게 끝남 | 이름이 다른 두 파일로만 검사함(`test_stale_preview_does_not_overwrite_new_document`, `test_export_of_previous_document_does_not_replace_view`). 같은 이름이면 파일명 비교로는 구별되지 않음 | **부분** |
| 원본과 같은 경로 저장 차단, 같은 이름이면 새 이름, 취소 뒤 기존 결과 유지 | `test_refuse_saving_over_source`, `test_existing_target_gets_new_name`, `test_cancel_export` | 충족 |
| **디스크 부족·잠긴 파일** 뒤에도 원본·기존 결과 해시 유지 | 없음 (워커 쪽 이름 예약·덮어쓰기 금지 테스트만 있음) | **없음** |
| 한컴 변환 실패해도 JSON 저장, 재시도 시 기존 JSON 보존 | 미리보기 실패 후 재시도만 검사. 실패 상태에서 JSON 내보내기는 검사 안 함 | **부분** |
| 표가 있는데 PNG 0개 / OCR 빈 결과 구분 | `test_no_assets_state`, `test_ocr_outcomes`, 미생성 표 사유 줄 | 충족 |
| 결과 탭이 원본과 같아 보여 복원 성공으로 착각 | 결과 제목에 원본·결과 파일명, 결과 쪽수 따로 표시. 원본·결과 쪽수를 나란히 보여 주는 검사는 없음 | **부분** |
| 병합 셀 안 표·그림 누락을 문자 수로 못 잡음 | 복원 범위 문구는 워커가 결과 메모로 냄. 화면 테스트에 없음 | **부분** |
| **작은 창·200% 배율에서 메뉴 잘림, 키보드만으로 형식 선택·내보내기** | 없음 (`TEST-REVIEW.md` 7절의 형식 메뉴 키보드 조작) | **없음** |

## 3. 정리

- 충족: 11개
- 부분: 8개 (원문 위치 찾기, 원본 대조, 로고 OCR 화면 검사, 같은 이름 파일, 한컴 실패 시 JSON, 쪽수 나란히, 복원 범위 표시)
- 없음: 3개
  - **표·이미지 검색**: 기능부터 없음
  - **디스크 부족·잠긴 파일**
  - **작은 창·고배율·키보드만으로 조작**

"부분"과 "없음" 중 기능이 없는 것(검색, 결과 이미지에서 원문으로, 나란히 대조)은 테스트를 쓰기 전에 화면 동작을 먼저 정해야 합니다.
