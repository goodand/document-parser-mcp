# 중첩 표 복원 평가

동일한 rhwp 환경에서 원본 HWPX와 파싱 JSON으로 복원한 HWPX를 연다. 문서 전체의 표와 셀을 중첩 주소로 대응시키고, 두 대상 표의 원본·복원 렌더를 나란히 본다. 셀 주소, 병합, 텍스트가 모두 일치해도 화살표가 빠지거나 설명과 겹칠 수 있어 도형 트리와 렌더를 함께 확인한다.

## 기상청 사업설명자료에서 확인한 두 표

첫 표는 직접·간접 수행 절차를 나타낸 흐름도다. 두 번째 표는 2023년과 2024년의 관측소 수, 조밀도, 지진탐지시간을 비교한다. 아래는 두 표를 각각 분리한 뒤 원본과 복원본의 페이지 상단 400픽셀에서 RGB가 다른 픽셀 수를 센 결과다. 비교 범위와 렌더러를 고정했다. 수치에는 글자·테두리의 작은 위치 변화도 포함된다.

전체 원본과 복원본의 표·셀 레코드는 각각 76,495개였다. 같은 주소에서 서명(표 크기 또는 셀 병합·문단·텍스트)이 다른 레코드는 기존 293개에서 101개로 줄었다. 흐름도 65개와 연도 비교 표 38개에서는 차이가 0개였다. 이 비교는 한 실문서에 대한 결과다.

| 누적 적용한 변경 | 절차 표 | 연도 비교 표 |
| --- | ---: | ---: |
| 1. 원본 셀에 대응하는 벡터 도형 복원 | 46,416 | 39,384 |
| 2. 문단의 원본 줄 배치 보존 | 47,244 | 39,384 |
| 3. 글자 장평·자간·상대 크기·위치 보존 | 47,298 | 39,218 |
| 4. 구역 설정 전용 문단 중복 방지 | 42,021 | 32,669 |
| 5. 본문 표 앞에 생긴 빈 문단 중복 방지 | 18,565 | 19,331 |

2·3회차에는 흐름도의 픽셀 차이가 증가했다. 5회차에서 두 표 모두 차이가 줄었고, 흐름도의 원본 벡터 앵커 6개가 복원본과 일치했다. 도형 트리는 새로 발급한 객체 ID를 제외하고 비교했다.

표를 세로로 평행 이동해 위치 차이를 보정한 뒤 다시 세면 흐름도는 17,513→13,404픽셀, 연도 비교 표는 15,399→12,953픽셀이 다르다. 1회차의 세로 위치 차이는 각각 38픽셀과 41픽셀이고 5회차는 둘 다 2픽셀이다.

픽셀 차이 감소에는 표 전체의 세로 위치가 가까워진 효과가 포함된다. 흐름도 아래쪽의 화살표는 원본을 rhwp로 연 화면에서도 ‘예산 교부’와 ‘사업내역/결산 및 정산’ 설명을 가린다. 화살표를 아래로 옮긴 실험에서는 글자가 보였지만 원본에서 화살표가 설명 위에 있던 관계가 바뀌어 적용하지 않았다. 연도 비교 표의 오른쪽 화살표는 5회차에 원본 페이지 렌더에서 빠지고 복원본 페이지 렌더에서는 보였다. 따라서 두 렌더 간의 픽셀 일치도만으로 화살표가 제대로 보이는지 판정할 수 없다.

## 재검증할 때

표별 PNG 내보내기는 별도 경로로 검증했다. 연도 비교 표를 공개 추출 함수로 처리하면 두 연도 사이에 오른쪽 화살표가 표시된다. 원본 셀에 있는 단일 기호, SVG의 위치, 래스터의 빈 영역, 실제 설치 글꼴의 문자 지원을 확인한 경우에만 그 기호를 그린다. 이 보정은 원본 문서나 복원 HWPX를 편집하지 않는다.

1. 원본에서 직접 읽은 표·셀과 파싱 JSON을 비교한다. 여기서 빠진 셀은 파서에서 조사한다.
2. 같은 JSON을 복원한 HWPX의 표·셀과 대조한다. 새로 생긴 차이는 복원기에서 조사한다.
3. 원본과 복원본을 같은 환경에서 렌더한다. 표 영역과 원래 페이지를 모두 열어 화살표 방향, 설명과의 겹침, 마지막 행 잘림을 확인한다.
4. 그림만 든 문단과 글 끝에 그림을 붙인 문단을 각각 검사한다. 바이너리 HWP는 원본을 rhwp로 변환한 HWPX가 구조 비교의 기준이므로 변환 자체의 손실은 별도 확인이 필요하다.

저장소의 합성 자료로 회귀 검사를 실행할 수 있다.

```sh
python -m pytest tests/test_vector_anchor_roundtrip_crop.py tests/test_table_images.py
```
